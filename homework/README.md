# Транслятор учебного конфигурационного языка

## Общее описание
CLI-инструмент для трансляции текста на учебном конфигурационном языке в формат toml.

## Функции и настройки
- Поддержка комментариев
- Типы данных: числа, строки, словари.
- Константы и вычисление.
- Вывод синтаксических ошибок в stderr.

## Команды сборки и тестирования
- Установка зависимостей: `make install`
- Запуск тестов: `make test`
- Запуск линтера: `make lint`

## Примеры использования
```bash
cat examples/server_config.conf | ./run.sh
