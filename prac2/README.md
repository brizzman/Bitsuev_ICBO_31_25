# Dependency Graph Visualizer (Вариант 4)

## 1. Общее описание
Инструмент командной строки (CLI) для визуализации графа зависимостей пакетов. 
Программа считывает настройки из XML-файла конфигурации, валидирует их, 
строит граф зависимостей с помощью алгоритма DFS (с учетом максимальной глубины) 
и сохраняет его в виде изображения PNG или выводит в консоль (ASCII-дерево).

Инструмент использует исключительно стандартную библиотеку Python. 
Сторонние менеджеры пакетов (например, `pip`) и библиотеки для получения 
зависимостей не используются.

## 2. Описание всех функций и настроек
Приложение управляется через конфигурационный файл формата XML. 
Поддерживаются следующие параметры:

* `package` (строка, обязательно) — Имя анализируемого пакета.
* `source` (строка, обязательно) — URL-адрес репозитория или путь к файлу тестового репозитория.
* `test_mode` (логический) — Режим работы с тестовым репозиторием (`true`/`false`). По умолчанию `false`.
* `version` (строка, обязательно) — Версия пакета (например, `latest` или `1.2.3`).
* `output` (строка, обязательно) — Имя сгенерированного файла с изображением графа (например, `graph.png`).
* `ascii_mode` (логический) — Режим вывода зависимостей в формате ASCII-дерева (`true`/`false`). По умолчанию `false`.
* `max_depth` (целое число) — Максимальная глубина анализа зависимостей. 
  Значение `-1` означает отсутствие ограничений. По умолчанию `-1`.
* `reverse` (логический) — Режим вывода обратных зависимостей (кто зависит от пакета). По умолчанию `false`.

## 3. Описание команд для сборки проекта и запуска тестов

**Требования:**
* Python 3.8+
* Утилита `pytest` для запуска тестов
* Java (опционально, для запуска `plantuml.jar`, если утилита `plantuml` не установлена в системе)

**Запуск приложения:**
Для запуска используется скрипт `run.sh` (или `run.bat` на Windows), которому передается путь к XML-файлу:
```bash
./run.sh config.xml
```

**Запуск тестов:**
```bash
pytest tests/
```

## 4. Примеры использования

**Пример 1: Файл конфигурации `config.xml`**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<config>
    <package>flask</package>
    <source>pypi</source>
    <test_mode>false</test_mode>
    <version>latest</version>
    <output>graph.png</output>
    <ascii_mode>false</ascii_mode>
    <max_depth>3</max_depth>
    <reverse>false</reverse>
</config>
```

**Пример 2: Тестовый режим с ASCII-деревом**
Если указать `<test_mode>true</test_mode>`, `<ascii_mode>true</ascii_mode>` и `<source>test_repo.json</source>`, программа выведет дерево:
```text
Dependency Tree (ASCII):
[packageA]
├── packageB
│   └── packageD
└── packageC
```

**Пример 3: Визуализация PlantUML**
При стандартном запуске (без `ascii_mode` и `reverse`) программа сгенерирует файл `graph.puml` и попытается создать `graph.png`.
